      How this was built

      123 PDFs to one tested table

      DPNR posts each week's results as a PDF. A Python pipeline finds every sheet through the agency's public media feed, downloads it once, and reads the table by character position. dbt models in DuckDB clean the codes, merge 56 printed name spellings into 45 beaches, and run 30 tests. One test checks our results against DPNR's own press release.

      Found along the way: five sheets carried the previous week's date, a few values had typing slips like "1..57", and the Nov 13, 2026 press release left Sprat Hall off its list even though its sheet shows a safe result.

      1. 1Discover sheets via WordPress REST API
      2. 2Download with caching and SHA-256 fingerprints
      3. 3Extract rows with PyMuPDF character positions
      4. 4Load raw text into DuckDB
      5. 5Model and test with dbt (staging, intermediate, marts)
      6. 6Export JSON for this page, refreshed weekly
